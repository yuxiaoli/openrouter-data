动态图表，原来的样式

浏览器直接用快照数值绘制 SVG 图表。可分类、搜索、放大、查看数值及下载 SVG。手机上可在放大窗口选择“原尺寸”横向滚动。

每日更新，完整发布

GitHub Actions 校验与编译快照，再通过 GitHub Pages 发布。页面使用当前一份完整快照；定时任务可能延迟。

不把缺口画成零

不混合不同采集快照，不猜测未知单位。未完整日／周桶用空心末点与虚线标记。新数据验证失败时，不替换已经验证的完整快照。
