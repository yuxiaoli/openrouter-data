ABOUT THE DATA

读懂图中的数据

数据来源

数据来自 OpenRouter 的公开目录、榜单与统计信息，涵盖模型、价格、应用和用量趋势，不包含个人账户用量。

浏览与下载

按分类或关键词寻找图表，放大查看细节，或下载 SVG。每张图下方提供数据来源与数值；手机上可选择“原尺寸”左右滚动。

更新时间

图表随每日数据更新。最新数据尚未可用时，页面展示最近一次完整结果，采集时间与更新状态见页面上方。

如何阅读图表

空白表示未提供数据，不等于零。序列末端的空心点和虚线表示尚未结束的统计周期。各图的单位、时间范围与样本限制可在图下查看。
